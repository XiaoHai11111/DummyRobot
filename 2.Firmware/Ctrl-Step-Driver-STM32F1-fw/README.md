驱动故障上报、保持/清错/使能协议以及配套 F4 升级步骤见 [驱动故障与恢复](../../5.Docs/驱动故障与恢复.md)。短按按键 2 清错后保持 STOP，不会自动追赶旧目标。

### 20 kHz 控制周期与 CAN 响应

抗积分饱和使用编译期除数 128/1024，避免 Debug 的 `-Og` 在每次循环生成两次 64 位软件除法。实时控制、规划、编码器与驱动路径始终按 `-O2 -fno-fast-math` 编译。DWT 统计正常控制耗时（包括编码器读取）；连续三次超过 45 us 预算时锁存 `0x80` / 状态 6，触发本地保持。故障显式清除后仍保持 STOP。

配套 F4 的 `#GETTIMING 1..6` 可读取最后/最大 CPU 周期数和累计超预算次数，72 MHz 下除以 72 为微秒。历史值仅在重启归零。校准任务不计入此检测。

固件应用区限为 95 KiB；`0x08017C00..0x0801FBFF` 是编码器校准区，最后 1 KiB 是 EEPROM 配置区。按 HEX 指定页升级并保留这些区域，六个节点共用镜像，各自节点 ID 和参数保留在配置区。
