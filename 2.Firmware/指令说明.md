# F4 ASCII 与 fibre CLI 指令说明

本文描述当前 `Core-STM32F4-fw` 对外暴露的指令。ASCII 指令同时适用于 USB CDC 和 UART4；UART5 保留给应用外设。fibre CLI 通过 `3.Software/CLI-Tool/run_shell.py` 连接后使用，根对象通常是 `dev0`，机器人对象为 `dev0.robot`。

约定：

- `<joint>` / `joint_x`：关节编号 `1..6`，腕部专用命令只接受 `4` 或 `5`。
- `<mode>`：`1=SEQ`、`2=INT`、`3=TRJ`、`4=TUN`、`5=DRAG`。
- `store`：是否写入 F1 EEPROM。`1` 持久化，`0` 或省略只改 RAM。
- `scale`、`gain`、`limit_a`：浮点参数，范围见各条说明。
- 所有浮点参数必须有限；多写参数或缺少必需参数会返回 `error ...`。

## ASCII 指令

### 使能、状态与诊断

| 指令 | 说明 |
|---|---|
| `!STOP` | 立即停止当前运动并清空运动队列。 |
| `!START` | 使能机器人和夹爪；若被故障或安全检查阻止，返回错误。 |
| `!DISABLE` | 关闭机器人和夹爪使能。 |
| `!CLEARFAULT` | 清除可恢复故障；通常需要先禁用并检查驱动/CAN。 |
| `#GETSTATUS` | 返回 `oks enabled mode fault_mask J1_fault ... J6_fault`。 |
| `#GETCAN` | 返回 `okc rx tx unexpected_errors tx_aborts last_error bus_error_status`。 |
| `#GETDRV <joint>` | 返回 `okd joint feedback_age_ms driver_state fault_flags robot_fault fault_age feedback_count`。`feedback_age_ms` 为 `UINT32_MAX` 表示未收到反馈。 |
| `#GETTIMING <joint>` | 回读 F1 控制周期统计，返回 `okt joint last_cycles peak_cycles overruns`；旧 F1 会超时。 |
| `#GETTELEM <joint>` | 回读 F1 位置/速度/电流遥测，返回 `okm joint q_tick dq_tick i_tick q_deg dq_deg_s i_cmd_motor_a driver_state fault_flags status_supported`。电流是 F1 指令电流，不是 ADC 实测电流。 |
| `#GETJPOS` | 返回六轴当前关节角 `okj j1 ... j6`，单位度。 |
| `#GETLPOS` | 返回末端笛卡尔位姿 `okl x y z a b c`。 |

### 运动控制

| 指令 | 说明 |
|---|---|
| `#CMDMODE <mode>` | 设置控制模式，范围 `1..5`。模式 5 为拖动模式。 |
| `>j1,j2,j3,j4,j5,j6[,speed][,gripper][,grip_current]` | 关节运动。`>` 使用顺序/连续轨迹语义，具体等待行为取决于当前模式。 |
| `@x,y,z,a,b,c[,speed][,gripper][,grip_current]` | 笛卡尔运动。`@` 最多允许 7 个参数。 |
| `speed` | 可选，范围 `(0,100]`；省略时沿用当前关节速度比例。 |
| `gripper` | 可选，夹爪开度，范围 `0..45` 度。 |
| `grip_current` | 可选，夹爪电流比例，范围 `0..1`。 |
| `#GRIP <angle>` | 设置夹爪开度 `0..45` 度，机器人必须已使能且无故障。 |
| `#GRIP_CURRENT <current>` | 设置夹爪电流比例 `0..1`，机器人必须已使能且无故障。 |

运动命令的 `speed`、`gripper`、`grip_current` 只在机器人已使能且命令未被新一代命令取代时生效。返回 `ok` 表示队列接收或运动提交成功；`error motion rejected or interrupted` 表示被拒绝、失效或被中断。

### 通用重力补偿

六轴共用同一套模型。不受重力影响的轴应把系数配置为 `0`，而不是使用单独的腕部模型结构。

| 指令 | 说明 |
|---|---|
| `#GRAVITY_FF_ON` | 打开位置模式重力前馈。 |
| `#GRAVITY_FF_OFF` | 关闭位置模式重力前馈。 |
| `#GRAVITY <joint> <scale>` | 设置该轴重力模型比例，`scale` 范围 `0..1`。 |
| `#GRAVITY_MODEL <joint> <a_per_nm> <bias_a> <limit_a>` | 设置该轴 `A/N·m` 比例、偏置 A 和限幅 A。`a_per_nm` 范围 `-10..10`，`bias_a` 范围 `-1..1`，`limit_a` 范围 `(0,3.3]`。 |

`#WRIST_GRAVITY` 和 `#WRIST_GRAVITY_MODEL` 是 J4/J5 的历史兼容入口，内部映射到同一套通用模型；兼容入口的 `a_per_nm` 只接受非负值。

### 拖动、摩擦与相位补偿

| 指令 | 说明 |
|---|---|
| `#DRAG_GAIN <damping> <friction_alpha> <current_limit>` | 设置 F4 拖动环参数。`damping 0..0.2`、`friction_alpha 0..1`、`current_limit 0.1..1.5 A`。 |
| `#GETDRAG` | 返回 `okg mode gravity_enabled damping friction_alpha current_limit feedforward_seq drag_seq`。 |
| `#LOCALCOMP <joint> <damping> <coulomb> <viscous> <deadzone> <limit> [store]` | 设置 F1 本地摩擦补偿五列参数。单位依次为 `mA/(motor rev/s)`、`mA`、`mA/(motor rev/s)`、`0.001 motor rev/s`、`mA`。死区会被 F4/F1 钳到下限。 |
| `#SETALLPARAMS` | 机器人禁用时，把 DCE、摩擦补偿和持久化相位参数一次性下发到六块 F1 EEPROM。 |
| `#GETCOMP <joint>` | 查询 F1 当前实际生效的五列摩擦参数和四列相位系数，返回 `okcomp joint local damping coulomb viscous deadzone limit harm eSin eCos oSin oCos`。 |
| `#SETCOMP <joint> <damping> <coulomb> <viscous> <deadzone> <limit> <store> <eSin> <eCos> <oSin> <oCos>` | 一次性设置并可选持久化摩擦参数和相位系数。各相位系数范围 `-500..500 mA`。 |
| `#WRIST_GRAVITY <joint> <scale>` | J4/J5 兼容入口，映射到 `#GRAVITY`。 |
| `#WRIST_GRAVITY_MODEL <joint> <a_per_nm> <bias_a> <limit_a>` | J4/J5 兼容入口，映射到通用重力模型。 |
| `#WRIST_HARMONIC <joint> <eSin> <eCos> <oSin> <oCos>` | 运行时设置 J4/J5 的相位补偿，范围每项 `±500 mA`；机器人移动时拒绝。 |
| `#WRIST_SPEED <joint> <enable>` | 启用/关闭 J4/J5 本地速度补偿状态位；需要新 F1 协议确认。 |
| `#WRIST_FRICTION <joint> <scale> <limit>` | 设置 J4/J5 拖动摩擦助力比例 `0..1` 和限幅 `1..500 mA`。 |
| `#GETWRIST <joint>` | 读取 J4/J5 的重力、摩擦、速度、状态、方向和相位回读，返回 `okw ...`。 |
| `#WRIST_RESET [joint]` | 关闭 J4/J5 或单个腕轴的重力与本地 RAM 助力；省略关节时同时复位 J4/J5。 |

`#SETALLPARAMS` 使用的参数表定义在 `Robot/instances/dummy_robot.h` 的 `DCE_KP`、`DCE_KV`、`DCE_KI`、`DCE_KD`、`LOCAL_COMP`、`ALL_HARMONICS_MA`。F1 烧录时只改 CAN ID，不改参数；烧录完 F4 后调用一次 `#SETALLPARAMS` 统一下发。

当前 `#GETCOMP <joint>` 的四列 `harm` 来自 F1 命令 `0x29..0x2C` 的实际生效快照；如果 F1 尚未把 EEPROM 持久化谐波同步到查询页，回读可能为 `0 0 0 0`，这不等于 `ALL_HARMONICS_MA` 未配置。

## fibre CLI 指令

启动示例：

```bash
cd 3.Software/CLI-Tool
python run_shell.py --path serial:/dev/ttyACM0
```

连接后 CLI 变量按发现顺序命名，例如 `dev0`。根对象属性：

| 名称 | 类型 | 说明 |
|---|---|---|
| `serial_number` | 只读属性 | 设备序列号。 |
| `get_temperature()` | 函数 | 返回芯片温度。 |
| `robot` | 对象 | 机器人对象，见下节。 |

## 部署顺序建议

1. 六块 F1 只改 CAN ID 后烧录，不改参数。
2. F4 烧录后确认 USB CDC 与 `/dev/ttyACM0` 正常出现。
3. 机器人禁用状态下执行 `#SETALLPARAMS`，或 CLI 执行 `dev0.robot.set_all_joint_params()`。
4. 用 `#GETCOMP 1` 到 `#GETCOMP 6` 查询各轴实际生效参数。
5. 进入 `#CMDMODE 5` 做拖动验收；若仍出现抱紧或自激，先降低对应轴的 `#WRIST_FRICTION`、`#DRAG_GAIN` 或相位系数，再复测。
