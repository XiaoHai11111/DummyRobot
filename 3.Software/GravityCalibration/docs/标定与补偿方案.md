# 从单关节标定到全姿态重力补偿

## 1. 推荐路线与边界

你的思路可以作为第一轮实验，建议扩充为：

```mermaid
flowchart LR
    A[核对坐标、负载与限流] --> B[采集位置、速度、电流指令]
    B --> C[单轴低速正反向往复]
    C --> D[同角度同速度配对]
    D --> E[局部重力电流与摩擦]
    E --> F[多固定姿态与已知负载]
    F --> G[全姿态重力模型]
    G --> H[位置闭环加重力前馈]
    H --> I[独立拖动模式]
```

第一轮最有价值的成果是可重复的 **`i_g(q)` 重力等效电流模型**，不必一开始就知道每个连杆的质量、质心和电机力矩常数。以此验证采集、符号、摩擦分离和前馈方向。之后需要全姿态补偿和拖动，再完善电流—输出力矩标定以及全姿态模型。

本次代码实现采集和局部离线拟合，并提供现有 MJCF 的重力预览；前馈控制和拖动的实机接入属于下述后续阶段。没有真实实验数据，无法现在给出真实参数或证明拖动性能。

## 2. 从现有代码得到的关键结论

**电流不是实测值。** `GetFocCurrent()` 读的是 DCE/PID/电流模式最终给驱动器的指令；TB67H450 用参考电压控制线圈电流。代码中虽有 PA0/PA1 ADC DMA，但没有将其转换为相电流并反馈给控制器的实现。先命名为 `i_cmd`，可以在低速、驱动电流跟随良好时作为力矩代理量，其误差仍需实验评估。芯片的 VREF/电阻关系描述的是设定峰值电流，不等于 MCU 已经测到的瞬时电流，见 [Toshiba 数据手册，第 10 页](https://toshiba.semicon-storage.com/info/TB67H450FNG_datasheet_en_20201126.pdf?did=65346&prodName=TB67H450FNG)。

**查询命令本来就有。** F1 `0x21/0x22/0x23` 分别返回 A、rev/s、rev；缺的是 F4 电流/速度接收和上位机采集出口。本次已补齐 `#GETTELEM`，不需要为读取指令电流重新设计 F1 电流环。

**重力前馈要加在位置闭环中。** 当前 F4 持续发位置目标，F1 收到 `0x07` 会进位置模式，`0x03` 又会切进电流模式。交替发送两种指令会造成模式争用，不能构成稳定的“位置 + 电流前馈”。

**单一固定姿态只能得到局部曲线。** J2 的重力受 J3 和腕部/工具姿态影响，J3 也受末端构型影响；其他关节固定一次、只扫一次，不足以覆盖整个工作空间。J1 若与重力方向平行，理想刚体重力力矩为零，电流变化主要要检查摩擦、线缆和基座倾斜。J4/J5/J6 不能仅凭“腕部轴”就假定重力为零，偏心相机和工具会改变结果。

## 3. 实验前统一约定

### 3.1 坐标

采用 F4 `#GETJPOS` 的实际关节角，离线模型统一转为 rad，速度 rad/s，力矩 N·m，电流 A。F1 原始位置是电机转数，不能直接拿来做关节正弦拟合。方向/减速比/偏置完整表见 [固件接口](固件接口.md)。

第一轮对每个轴做一次已检查的小幅正向运动，核对：实际角度增长、速度为正、模型运动方向一致。电流符号不必与速度同号——下落/制动时本来就可能反号。不要仅靠“正速度应有正电流”决定符号。

### 3.2 安装与负载

- 固定基座，记录是否水平；模型重力方向必须对应真实基座方向。现有模型默认 `[0,0,-9.81] m/s²`。
- 记录夹爪开合、相机、安装支架、工具/工件质量及安装位置、供电电压和线缆走向。第一轮全程保持一致。重力模型要包含这些末端负载。
- 其他关节用位置闭环保持。外部夹具若托住正在辨识的关节下游连杆，会分担重力、破坏实验。支撑仅用于防坠或专门的已知外力实验，正常采样时不能形成未知受力。
- 使用已经正常工作的编码器校准、零位和位置控制参数，保留故障保护。标定期间不要同时改 DCE 增益、限流、加速度或零位；改动后重新分组采集。
- 做一致的预热流程，等电流/摩擦重复性稳定，并记录温度；当前协议没有温度读数，需人工测量或注明未知。不要把冷机和热机数据混成一套参数。

### 3.3 可检查的实验范围

先确认工具、线缆、自碰撞和工作台空间，选中间姿态；第一轮用 5–10° 总行程、1°/s 检查。通过后逐步扩大至能覆盖明显重力变化的范围，例如条件允许时 40–80° 总行程；范围不是所有轴通用的硬性要求。

普通单轴采集按原软件限位校验；J4/J5 严格批采集改用历史交集，其中 J4 收紧为 `[-170,170]°`。这组限位不能替代实际机械余量或碰撞验证。尤其 J6 的软件多圈范围不代表线缆允许多圈。不能把示例配置直接认定为现场安全姿态。

## 4. 第一阶段：把测量链路验证清楚

1. 更新 F4，验证 `#GETTELEM 1..6`。电流必须保留正负号；禁止 `abs(i)` 后用于重力拟合。静止位置仍有重力保持电流是正常现象。
2. 对比 `#GETJPOS` 与新接口 q；验证关节速度约等于实际角度的时间差分，不能误用电机 rev/s。通过小幅运动检查比例、符号、J3 偏置。
3. 先按 20 Hz 采活动轴的 q/v/i，同时保存全部六轴实际角度。实际采样率由时间戳计算，不假设串口请求总能按计划完成。每条记录保留状态、故障和源信息。
4. 检查三帧接收时间差、丢帧和串口往返时间。本版默认要求时间差 ≤10 ms；4°/s 时 10 ms 约对应 0.04° 位移，仅作为误差量级说明。检查 `#GETCAN` 错误计数和 `#GETTIMING` 是否恶化。
5. 若以后需要实测电流：核实板卡原理图/实际采样点，设计零偏与增益标定；以合适时序采两相电流，并按电角度投影到产转矩方向。两相幅值或电源母线电流都不能直接代替带符号的产转矩电流。当前 ADC 非同步连续采样配置不能直接宣称满足这些要求。

第一轮只需验证 `i_cmd` 的可重复性。若电源压降、高速反电动势、斩波误差或热漂移导致指令与实际力矩关系明显变化，再优先补测量硬件；不要用统计拟合掩盖电流跟随问题。

## 5. 第二阶段：单关节慢速往复

### 5.1 一次实验的操作顺序

1. 选活动关节 j，配置固定姿态 P 和经检查的角度区间。先用现有控制界面到位，关闭占用串口的客户端。
2. 第一轮 `cycles=1`、速度 1°/s；通过后正式采集每个速度 3–5 个完整往复，建议速度组 1、2、4°/s。太慢会长期陷入粘滞/爬行，不是越慢越好。
3. 执行本目录 `collect.py`。脚本先 `!STOP` 清旧运动并检查初始状态/姿态，要求已经处于模式 2（可中断位置模式），再 `!START`，活动轴先到下端点，然后正反向扫描。其他轴目标保持开始时的实测角度。脚本不发送 `#CMDMODE 2`，因为现有固件切模式会重设加速度；需要时在整组实验前手动完成切换并记录。
4. 每次到达端点后停留至少 1 s。端点停留、初始靠近段、换向及加减速样本不参与主拟合。现有 F1 加速度配置不在本脚本中更改；必须保留实际速度观测，用筛选排除转场。
5. 整轮结束后 `!STOP` 保持，不自动回原点、不自动卸力。再单独采一轮作为验证集，保留全部元数据和中途失败记录。

可先用有可靠支撑/急停条件的 J2 小行程验证采集质量，再完成 J3、J5，以及工具偏心明显时的 J4/J6；J1 用于摩擦/线缆检查。不要为了“所有轴都有重力参数”强行给理论接近零的轴拟合大重力项。

### 5.2 推荐实验矩阵

| 组别 | 变量 | 每组建议 | 用途 |
|---|---|---|---|
| 单姿态基线 | 只扫目标关节 | 1°/s，1 周期小行程，再扩展 | 验证坐标、采集和电流余量 |
| 正式局部实验 | 固定姿态 P0，改变速度 | 1/2/4°/s，各 3–5 周期 | 重力与摩擦分离、检查速度依赖 |
| 姿态泛化 | 改其他关节固定角度 | 每目标轴先 3–5 组姿态 | 检查下游构型的影响 |
| 负载标定 | 相同轨迹，空载/已知附加载荷 | 至少 2–3 档适宜负载 | 估计电流到输出力矩比例 |
| 留出验证 | 未用于拟合的完整周期/姿态/日期 | 独立采集 | 评估泛化与热漂移 |

改变固定姿态时，J2 优先改变 J3 的弯曲程度和 J5 的工具朝向；J3 优先改变上臂姿态及腕部朝向；腕部轴应改变重力相对其轴线的方向及工具偏心方向。具体角度由现场无碰撞区域确定，不给一套未经验证的全臂自动运动矩阵。

局部模型每个 `pose_id` 单独拟合。多姿态数据同时保留，为后续完整 `g(q1,...,q6)` 模型提供输入；不能将它们都投入同一个 `sin(qj),cos(qj)` 拟合器。

## 6. 第三阶段：从数据分离重力与摩擦

采用关节正方向电流 `i = s * i_cmd_motor`。低速近似下：

```text
K_j * i_j ≈ g_j(q) + f_c,j * sign(dq_j) + b_j * dq_j + 偏置/其他损耗
```

`K_j` 是输出侧等效 N·m/A 比例。暂不知道它时，直接把等式除以 `K_j`，在 A 单位拟合，不虚构 N·m。

在其他关节姿态一致、同一角度、正反向速度幅值相近的情况下：

```text
i_plus(q, v)  ≈ i_g(q) + i_c + b_i*v
i_minus(q,-v) ≈ i_g(q) - i_c - b_i*v
i_g_pair     = (i_plus + i_minus)/2
i_loss_pair  = (i_plus - i_minus)/2
```

这是针对近似奇对称摩擦的分离方法。减速器正反驱动效率差异、线缆预紧、背隙和速度相关电流误差可能使平均值仍有偏差；应检查多速度、多周期和负载重复性。静态停住时的摩擦是区间约束，单次保持电流不等于唯一的重力电流。

本次工具的处理方式：

- 按文件和完整周期分组，在默认 1° 角度箱、0.5°/s 速度幅值箱内分别取正反向电流中位数；每方向至少 3 个样本，再检查实际平均角度和速度的匹配程度。四列配对输出的最后一列是正反向实际速度幅值的平均值。
- 默认用六轴位置差分及平滑差分筛选加速度，并保留 F1 原始速度在 CSV 中；默认 `|ddq|≤2°/s²`、`|dq|≥0.3°/s`，去掉换向或数据间断前后 0.4 s。阈值是可调的实验起点，不是惯性力矩必然可忽略的保证，要通过多速度结果一致性验证。
- 剔除故障、非扩展状态、未启用、异常时间偏差和 `|i|≥0.9*实际限流` 的样本；其他关节位置跨度超过 0.5° 则拒绝整个局部实验。
- 拟合 `i_g(qj)=A*sin(qj)+B*cos(qj)+C`；保存设计矩阵秩/条件数。角度范围太窄时正弦、余弦和常数可能近似相关，更多同位置样本不能解决该问题。
- 正反向半差另行导出。只有一个速度时只得到该速度下的方向损耗，不能分开识别库仑摩擦与粘性系数；多个不同速度才可以回归 `i_loss≈i_c+b_i*|dq|`。本版只导出这些损耗点，不自动启用摩擦补偿。

验收时至少画/检查：正反向电流—角度曲线、配对平均与拟合、配对半差—速度、验证残差—角度、各周期重叠程度。留出**完整周期/实验文件**，不要把相邻采样随机拆成训练/验证，避免虚高的拟合成绩。

建议初始工程门槛：独立验证集平均偏差接近零，RMSE 小于该轴重力电流有效变化幅值的约 5–10%，无明显姿态/方向相关残差，且绝对最大误差低于预先允许的电流/力矩误差。重力幅值接近零时只用绝对误差和噪声基线；不要用接近零的分母算相对误差。这些门槛要按实机目标调整，并非认证标准。

## 7. 第四阶段：电流—力矩标定与全姿态模型

### 7.1 什么时候需要力矩标定

如果只在固定姿态附近做位置重力前馈，经过验证的 A 单位曲线已经可以使用。若要解释质量、质心、未知负载或控制拖动力，则需要可信的力矩尺度。

电机铭牌的保持力矩除以额定电流不能直接当精确转矩常数。近似 `K≈N*η*K_t` 中的传动效率可能随方向、负载、温度变化；应把它视为待检验的等效模型。

可行标定方法：

1. 在已知关节姿态/相同慢速轨迹，采无附加载荷和已知附加载荷的正反向配对平均电流。
2. 已知质量 `m`、相对关节轴的位置向量 `r` 和轴单位向量 `a`，额外需要抵消的重力力矩为 `Δtau_g = -a·(r×m*g_vector)`；复杂链用工具雅可比或模型势能差计算。必须使用实际重力力臂，而不是工具长度。
3. 对多角度、多负载点回归 `Δtau_g ≈ K_j * Δi_g_joint`，检查符号、截距、线性和正反向差异。不用分母接近零的点。附加载荷也会改变摩擦，因此要看拟合残差而不能只算一个比值。
4. J1 轴若竖直，附加重物不能有效激励其重力力矩；用已知切向力和力臂/输出力矩传感器作独立实验。J6 若工具重心恰在轴上也一样。

不要用未知接触力下的堵转电流作力矩标定。仅有电流和角度且未知 `K_j` 时，质量/重心与执行器增益存在尺度和耦合歧义；可以辨识某些组合，但不能声称每个物理参数唯一。

### 7.2 全姿态重力模型

优先复用 `3.Software/DummyMujoco` 的几何模型，核对真实工具质量、质心、关节轴、零位以及基座方向。现有模型主要是先验，尤其相机/支架可能不在模型里。`gravity_preview.py` 已按配置映射 q，令速度为零，从 `qfrc_bias` 提取重力项；不会把接触力或关节阻尼当成重力。[MuJoCo 动力学字段说明](https://mujoco.readthedocs.io/en/stable/computation/index.html)

全姿态物理标定可使用：

```text
g(q) = Y_g(q) * beta_g
tau_pair = diag(K) * i_g_pair
min_beta sum || W^(1/2) * (Y_g(q)*beta_g - tau_pair) ||²
```

重力主要约束质量及一阶质量矩 `m*c` 的可辨识组合，不能靠静态/准静态数据识别全部转动惯量。通过 SVD/带列主元 QR 选择可辨识基参数，检查有效秩和条件数；必要时引入可信 CAD 先验与物理约束。不要直接求逆奇异的 `YᵀY`，也不要把最小二乘的任意分配解释为唯一的逐连杆质心。

现有 C++ Pinocchio 示例已经展示 `rnea(q,0,0)`；可用 `computeJointTorqueRegressor(q,0,0)` 构造重力回归矩阵，再处理固定连杆、夹爪和已知工具负载。`computeGeneralizedGravity` 等价于零速度/加速度的 RNEA，见 [Pinocchio 算法文档](https://gepettoweb.laas.fr/doc/stack-of-tasks/pinocchio/jnrh2023/template/algorithm.html)。正式拟合使用跨构型数据，验证集留出整个固定姿态组合。

若暂时没有力矩尺度，也可在正确的全姿态几何特征上拟合各轴 A 单位模型；这属于经验补偿模型，不输出物理质量。当前 `fit_local.py` 未实现这种多姿态模型，禁止绕过它的固定姿态检查拿局部结果替代。

### 7.3 完整动力学识别放在后面

要识别惯量、科氏项和动态摩擦，还需同步的 q/v/i/时间戳、受限多频激励及可靠的加速度估计；模型为 `tau=Y(q,dq,ddq)*beta + friction`。单轴慢速实验不能提供足够惯性激励。先解决测量质量和可辨识性，再考虑多正弦/Fourier 轨迹，不能通过增加静态数据量替代激励设计。[系统辨识的模型、观测与实验设计背景](https://underactuated.mit.edu/sysid.html)

## 8. 第五阶段：在位置闭环内启用重力前馈

这一步需要后续修改 F1/F4，详见固件接口文档；本次没有自动启用补偿。

```text
i_ff_motor = s * i_g_joint(q_actual)               # 经验电流模型
或 i_ff_motor = s * g_joint(q_actual)/K_j          # 物理力矩模型
i_total = saturate(i_feedback + alpha*i_ff_motor, ±I_limit)
```

1. 用**实际**全部关节角评估重力，先离线回放日志核对符号与幅值；局部模型只在其固定姿态域内评估。
2. 在 F1 位置闭环中增加独立前馈入口，总输出限幅并重新处理积分抗饱和；不能改变到纯电流模式来替代前馈。
3. 初次保持原反馈增益，用小比例逐步验证，例如 `alpha=0→0.1→0.25→0.5→1`。这些是分阶段实验点，不是脚本自动连续执行的序列。每步检查保持误差、振荡、方向、限流与温升，再决定是否提高。
4. 增加前馈变化率限制、超时和有效域处理；模型失效则退回原位置反馈，故障按现有保持策略处理。前馈变更时处理原有积分贡献，避免同一重力被暂时重复补偿。
5. 重复完全相同的静止姿态和低速轨迹，比较位置误差、反馈分量/积分负担、总电流、故障、时间裕量和温度。

**重力前馈不会使负载所需的总电流凭空减少。** 主要收益是减少误差驱动的反馈输出、改善跟踪和降低对高刚度/积分的依赖。原控制器已经有积分时，单看静态位置误差或总电流可能看不出收益，应新增 `i_feedback/i_ff/i_total` 日志。第一阶段不叠加摩擦前馈，以便判断重力模型是否正确。

## 9. 第六阶段：拖动示教

先通过多姿态位置前馈，再设计独立的重力/阻尼拖动模式：

```text
tau_cmd = g_hat(q) - D*dq + tau_friction_optional
```

`D` 取正阻尼，量纲与关节速度一致。开始只做重力和小阻尼，暂不完全抵消库仑摩擦；`sign(dq)` 在零速附近可能引起抖动，需要死区、连续近似及实机稳定性验证。减速器摩擦、反驱效率、结构背隙和电流测量误差会限制拖动轻盈程度，完成重力补偿并不保证能轻松反驱。

必须新增：停止 F4 普通位置目标流的模式切换、F1 模式确认、本地关节/速度限制、失联策略、前馈过期处理和可预测的退出保持。当前的 `#CMDMODE 4` 是调参模式，不能直接当作这个拖动模式。

拖动开始与结束先有支撑并记录起始姿态，逐轴验证再六轴联动。退出时以当前实测角度无跳变地建立位置目标，避免追赶拖动前的旧目标。

## 10. 阶段验收与当前限制

| 阶段 | 通过条件 | 不通过时优先处理 |
|---|---|---|
| 读数 | 单位/方向一致，完整状态，无过大时间差和 CAN 错误 | 协议、坐标、时序 |
| 局部识别 | 正反向配对充分，跨周期重复，独立验证误差满足目标 | 摩擦、转场、温漂、角度覆盖 |
| 多姿态模型 | 未参与拟合的构型也能预测，力矩尺度合理 | 工具质量/质心、映射、基参数秩 |
| 位置补偿 | 同轨迹下误差/反馈负担改善，无新振荡和饱和 | 前馈符号、积分、总限幅、模型失效处理 |
| 拖动 | 全域可控、限制和失联有效、退出无跳变 | 机械反驱性、阻尼、模式/租约机制 |

普通 `collect.py` 是有限区间的位置扫描工具；J4/J5 严格批采集额外使用 `pose_sweep_planner.py` 做六轴路线、非相邻自碰撞、地面和 TCP 的离线与在线几何检查。它仍没有六轴实时电流/温度监测，MJCF 也不能证明真实夹具、线缆或工作台无干涉。实时控制和 CAN 驱动安全机制继续由固件承担。

现有 F4 在 PC 断连后仍可继续向最近目标运动；`collect.py` 在正常异常退出时尝试 `!STOP`，但 `kill -9`、断电或拔线不能保证停止命令发出。正式无人值守采集前应实现并验证运动租约/心跳超时保持。当前实验应有人监护，保持可用的独立急停。

开始真正采集前仍需你填写：各轴实际限流、当前已烧录固件版本、工具/相机/支架的配置，以及现场验证后的姿态和行程。这些信息不能从源代码默认值可靠推断。
